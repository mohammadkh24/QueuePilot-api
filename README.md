# QueuePilot

سامانه مدیریت نوبت‌دهی و صف انتظار برای کسب‌وکارهای خدماتی؛ توسعه‌یافته با NestJS، PostgreSQL، TypeORM و Socket.IO، همراه با رابط فارسی React.

## Backend

```bash
npm install
npm run start:dev
```

پیش از اجرا، فایل `.env` را با متغیرهای موردنیاز پروژه تنظیم کنید. مستندات Swagger در مسیر `/docs` در دسترس است.

## Frontend

```bash
cd frontend
npm install
```

از `frontend/.env.example` یک فایل `.env` بسازید و `VITE_API_URL` را روی آدرس بک‌اند قرار دهید. سپس:

```bash
npm run dev
```

## قابلیت‌ها

- ثبت‌نام، ورود و تمدید توکن JWT
- مدیریت کسب‌وکار و خدمات
- ثبت و مدیریت نوبت‌ها
- مدیریت چرخه وضعیت صف
- ثبت مراجعه‌کننده حضوری بدون ساخت حساب کاربری
- رویدادهای زنده صف با Socket.IO
- لندینگ فارسی، مرور کسب‌وکارها، رزرو آنلاین و پنل مدیریت RTL

جزئیات راه‌اندازی فرانت‌اند و مسیر صفحات در `frontend/README.md` آمده است.
